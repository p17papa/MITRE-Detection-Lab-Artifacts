# MITRE-Detection-Lab-Artifacts
Αποθετήριο με **PCAP/PCAPNG** datasets και **custom detection rules** για **Snort**, **Suricata** και **Wazuh**, που δημιουργήθηκαν σε εργαστηριακό περιβάλλον (VirtualBox NAT) κατά τη σύγκριση IDS/SIEM με σενάρια **MITRE Caldera** και **Atomic Red Team** (ευθυγραμμισμένα με **MITRE ATT&amp;CK**).
